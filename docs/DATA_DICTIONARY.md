# DATA_DICTIONARY.md - Table & Field Specifications

This document defines the schema, data types, nullability, allowed values, and validation rules for all 15 tables generated by the Marketplace Seller Payout Data Generator.

---

## 1. Core Entity Tables (10)

### 1.1 `sellers`
Master record for marketplace sellers.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `seller_id` | STRING | No | PK | `SELL-NNNNNN` | Unique identifier generated by IdGenerator. |
| `business_name` | STRING | No | Unique | 3-64 chars | Synthetic vendor business name. |
| `contact_email` | STRING | No | Unique | Valid email format | Contact email address. |
| `onboarded_at` | TIMESTAMP | No | No | ISO 8601 (`YYYY-MM-DDTHH:MM:SS`) | Date seller registered; between mid-2025 and 2026-09-30. |
| `status` | STRING | No | No | `ACTIVE`, `WATCHLIST`, `SUSPENDED` | Current operational status as of 2026-10-31. |
| `status_updated_at` | TIMESTAMP | No | No | ISO 8601 | Timestamp of latest status update. |
| `country` | STRING | No | No | `US` | Fixed country code. |

### 1.2 `product_listings`
Catalog items offered by sellers.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `listing_id` | STRING | No | PK | `LIST-<seller_id>-NNNNNN` | Unique identifier incorporating parent seller_id. |
| `seller_id` | STRING | No | No | FK to `sellers.seller_id` | Foreign key referencing owning seller. |
| `title` | STRING | No | No | 5-100 chars | Synthetic product title. |
| `category` | STRING | No | No | `ELECTRONICS`, `APPAREL`, `HOME_KITCHEN`, `BEAUTY`, `SPORTS`, `BOOKS` | Product merchandise category. |
| `base_price_cents` | INTEGER | No | No | 100 to 500,000 | Price in integer USD cents ($1.00 to $5,000.00). |
| `created_at` | TIMESTAMP | No | No | ISO 8601 | Listing creation timestamp (must be >= `seller.onboarded_at`). |
| `deactivated_at` | TIMESTAMP | Yes | No | ISO 8601 or NULL | Timestamp listing was disabled (set if seller suspended). |

### 1.3 `commission_rules`
Marketplace commission rate schedules.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `rule_id` | STRING | No | PK | `RULE-NNNN` | Unique rule identifier. |
| `rule_type` | STRING | No | No | `STANDARD`, `NEW_SELLER_PROMO` | Tier or promo type. |
| `category` | STRING | No | No | Category enum or `ALL` | Targeted merchandise category. |
| `rate_bps` | INTEGER | No | No | 300 to 2500 (3.00% to 25.00%) | Commission rate in basis points (1 bp = 0.01%). |
| `priority` | INTEGER | No | No | 1 to 100 | Resolution priority; higher number takes precedence. |
| `effective_from` | DATE | No | No | `YYYY-MM-DD` | Start date of rule validity. |
| `effective_to` | DATE | Yes | No | `YYYY-MM-DD` or NULL | Expiration date of rule (NULL means currently active). |

### 1.4 `orders`
Header table for customer checkout orders.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `order_id` | STRING | No | PK | `ORD-2026-NNNNNN` | Unique order identifier. |
| `customer_id` | STRING | No | No | `CUST-NNNNNN` | Attribute identifying synthetic customer. |
| `order_status` | STRING | No | No | `SUBMITTED`, `PROCESSING`, `COMPLETED`, `CANCELLED` | High-level status of the entire order. |
| `total_gross_cents` | INTEGER | No | No | > 0 | Sum of all child `order_lines.total_gross_cents`. |
| `placed_at` | TIMESTAMP | No | No | ISO 8601 | Placed between 2026-01-01 and 2026-10-15. |

### 1.5 `order_lines`
Individual items purchased within an order.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `order_line_id` | STRING | No | PK | `<order_id>-NN` | Unique identifier (e.g., `ORD-2026-000001-01`). |
| `order_id` | STRING | No | No | FK to `orders.order_id` | Foreign key referencing parent order. |
| `seller_id` | STRING | No | No | FK to `sellers.seller_id` | Direct seller reference for join optimization. |
| `listing_id` | STRING | No | No | FK to `product_listings.listing_id` | Foreign key referencing catalog listing. |
| `quantity` | INTEGER | No | No | 1 to 10 | Units purchased. |
| `unit_price_cents` | INTEGER | No | No | > 0 | Price locked at time of order in integer cents. |
| `total_gross_cents` | INTEGER | No | No | `quantity * unit_price_cents` | Gross line amount. |
| `applied_rule_id` | STRING | No | No | FK to `commission_rules.rule_id` | Rule used to calculate commission. |
| `commission_rate_bps` | INTEGER | No | No | 100 to 3000 | Locked basis points rate. |
| `commission_cents` | INTEGER | No | No | `round_half_up(gross * bps / 10000)` | Locked commission amount. |

### 1.6 `fulfillments`
Shipment and delivery tracking (1:1 with OrderLine).
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `fulfillment_id` | STRING | No | PK | `FUL-<order_line_id>` | 1:1 identifier directly bound to order line. |
| `order_line_id` | STRING | No | Unique FK | FK to `order_lines.order_line_id` | Parent order line reference. |
| `carrier` | STRING | No | No | `UPS`, `FEDEX`, `USPS`, `DHL` | Logistics carrier. |
| `tracking_number` | STRING | No | Unique | 12-20 alphanumeric characters | Synthetic tracking code. |
| `fulfillment_status` | STRING | No | No | `PENDING`, `SHIPPED`, `DELIVERED`, `CANCELLED`, `FAILED_DELIVERY`, `RETURNED` | Current fulfillment milestone. |
| `shipped_at` | TIMESTAMP | Yes | No | ISO 8601 or NULL | Ship timestamp (must be >= `orders.placed_at`). |
| `delivered_at` | TIMESTAMP | Yes | No | ISO 8601 or NULL | Delivery timestamp (must be >= `shipped_at`). |
| `returned_at` | TIMESTAMP | Yes | No | ISO 8601 or NULL | Return delivery timestamp (must be >= `delivered_at`). |

### 1.7 `customer_reviews`

| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |

| `order_line_id` | STRING | No | Unique FK | FK to `order_lines.order_line_id` | Evaluated order line (max 1 review per line). |
| `rating` | INTEGER | No | No | 1, 2, 3, 4, 5 | Customer star rating. |
| `review_text` | STRING | Yes | No | Free text | Synthetic comment text. |
| `created_at` | TIMESTAMP | No | No | ISO 8601 | Review timestamp (must be >= `delivered_at`). |

### 1.8 `disputes`
Dispute claims raised by buyers.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `dispute_id` | STRING | No | PK | `DSP-2026-NNNNNN` | Unique dispute identifier. |
| `order_line_id` | STRING | No | Unique FK | FK to `order_lines.order_line_id` | Disputed order line (max 1 dispute per line). |
| `dispute_type` | STRING | No | No | `NOT_RECEIVED`, `NOT_AS_DESCRIBED`, `RETURN_DISPUTE`, `CHARGEBACK` | Reason for customer dispute. |
| `dispute_status` | STRING | No | No | `OPEN`, `RESOLVED_SELLER_WON`, `RESOLVED_BUYER_WON` | Adjudication outcome. |
| `amount_cents` | INTEGER | No | No | = `order_lines.total_gross_cents` | Disputed value in integer cents. |
| `opened_at` | TIMESTAMP | No | No | ISO 8601 | Dispute initiation timestamp. |
| `resolved_at` | TIMESTAMP | Yes | No | ISO 8601 or NULL | Resolution timestamp (NULL if still `OPEN`). |

### 1.9 `payouts`
Weekly financial disbursement summaries per seller.
| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `payout_id` | STRING | No | PK | `PAYOUT-2026-NNNNNN` | Unique payout identifier. |
| `seller_id` | STRING | No | No | FK to `sellers.seller_id` | Receiving seller. |
| `cycle_date` | DATE | No | No | `YYYY-MM-DD` (Mondays) | Settlement cycle date. |
| `total_cents` | INTEGER | No | No | Integer cents | Must match sum of child `payout_lines.amount_cents`. |
| `status` | STRING | No | No | `PAID`, `HELD` | `PAID` if eligible; `HELD` if seller suspended. |
| `generated_at` | TIMESTAMP | No | No | ISO 8601 | Batch generation timestamp. |

### 1.10 `payout_lines`

| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `payout_line_id` | STRING | No | PK | `PLINE-2026-NNNNNN` | Unique ledger line identifier. |
| `payout_id` | STRING | No | No | FK to `payouts.payout_id` | Parent payout summary. |
| `seller_id` | STRING | No | No | FK to `sellers.seller_id` | Owning seller. |
| `source_type` | STRING | No | No | `ORDER_LINE`, `DISPUTE`, `RESERVE` | Originating business entity. |
| `source_id` | STRING | No | No | FK to source entity | ID of referenced entity (`order_line_id`, etc.). |
| `entry_type` | STRING | No | No | `SALE`, `COMMISSION`, `REFUND`, `COMMISSION_REVERSAL`, `DISPUTE_DEDUCTION`, `RESERVE_HOLD`, `RESERVE_RELEASE` | Ledger entry classification. |
| `amount_cents` | INTEGER | No | No | Signed integer cents | Credit (+) or Debit (-) amount. |
| `rule_id` | STRING | Yes | No | FK to `commission_rules.rule_id` | Present only for commission entries. |
| `created_at` | TIMESTAMP | No | No | ISO 8601 | Ledger transaction timestamp. |

## 3. Event / Audit Tables (4)

| Field | Type | Nullable | Uniqueness | Allowed Values / Format | Description / Validation Rule |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `event_id` | STRING | No | PK | `EVT-STATUS-NNNNNN` | Unique event identifier. |
| `seller_id` | STRING | No | No | FK to `sellers.seller_id` | Target seller. |
| `previous_status` | STRING | No | No | `ACTIVE`, `WATCHLIST`, `SUSPENDED` | Prior operational state. |
| `new_status` | STRING | No | No | `ACTIVE`, `WATCHLIST`, `SUSPENDED` | Newly assigned state. |
| `reason` | STRING | No | No | 5-100 chars | Justification (e.g. `LATE_SHIPMENT_BREACH`). |
| `snapshot_late_rate_bps` | INTEGER | No | No | 0 to 10000 | Late shipment rate in basis points at evaluation. |
| `snapshot_dispute_rate_bps` | INTEGER | No | No | 0 to 10000 | Dispute rate in basis points at evaluation. |
| `evaluated_lines_count` | INTEGER | No | No | >= 0 | Number of eligible trailing lines evaluated. |
